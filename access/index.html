Installing it on Windows
  1. Open the downloaded Supplyline-Setup file. It installs and starts the game on its own; there is nothing to choose.
  2. The game is not signed with a Microsoft certificate yet, so Windows may show Windows protected your PC. Press More info, then Run anyway.
  3. If your browser holds the download back, open your downloads list and choose Keep.
  4. After that it updates itself: when a new version is ready, the menu offers a restart. Your saves stay where they are.
Opening it on a Mac the first time
  1. Open the downloaded file and drag Supplyline into Applications.
  2. The game is not signed with an Apple certificate yet, so the first time, macOS will say it cannot check it. Open System Settings, then Privacy and Security, and press Open Anyway next to Supplyline.
  3. If it says the app is damaged, open Terminal and run xattr -cr /Applications/Supplyline.app, then open it again.
  4. The Windows game updates itself. On a Mac, come back here for each new version; the game tells you when one is out.
