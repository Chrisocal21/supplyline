# Supply Yard / Distribution Warehouse: numbers draft

DRAFT. Every number here is my proposal, not a decision. Edit what feels wrong. Goods use only what exists today (no granite, fire wood, mulch yet).

## 1. Truck reach (hard limit, tiles one way)

Reach = vehicle base x driver rank.

| Vehicle | Base reach |
|---|---|
| Box Truck | 900 |
| Big Box Truck | 1400 |
| Big Rig | 2200 |
| Truck Fleet | 3300 |

| Driver rank | Multiplier |
|---|---|
| Rookie | x0.8 |
| Regular | x1.0 |
| Experienced | x1.15 |
| Veteran | x1.3 |
| Ace | x1.5 |

Highway tiles count as half a tile. Ports, airports and rail have no tile limit (they cost more to build and run).

## 2. Fuel

Paid per tile driven, loaded or empty, out of your cash.

| Vehicle | Fuel per tile |
|---|---|
| Box Truck | $0.10 |
| Big Box Truck | $0.22 |
| Big Rig | $0.50 |
| Truck Fleet | $1.40 |

Built (draft): about $0.0083 per unit of load per tile, the same for every class. 0.4 per tile for the Box Truck ate half the income of cheap goods like logs, so it was cut to 0.10. Example: Box Truck, 30 tiles each way = $6 fuel per round trip.

## 3. Wear

Built (draft): full wear at 4000 tiles. Wear per tile is multiplied by (1 + 2 x route length / reach): a short local run wears about x1, a run at max reach x3. A worn truck is up to 12 percent slower and carries up to 30 percent less. Chris said wear still needs more talking about.

## 4. Drivers

You pick from 3 applicants at a Warehouse or Yard, refreshed every few game days. Existing ranks and trip counts stay (0, 6, 20, 45, 90 trips).

| Rank | Hire fee | Wage per minute |
|---|---|---|
| Rookie | $0 | $2 |
| Regular | $60 | $4 |
| Experienced | $200 | $7 |
| Veteran | $500 | $11 |
| Ace | $1200 | $16 |

For reference a Box Truck upkeep is about $4.80 per minute.

New vehicle rule: moving a driver to a different vehicle class drops him one rank (trips reset to that lower rank's start). Same class = no drop. He climbs back by trips, and can climb above his hired rank (up to Ace).

## 6. Opening a town

A closed town opens when its Market has received 500 growth points (the Village step today is 2000). After that you can buy its Supply Yard.
