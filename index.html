How it plays

Your first ten minutes

A little guide shows you around. These are the steps.

  1. Build a Forestry CampPick a ringed forest spot. Trees give you logs.
  2. Buy a truck and lay a roadDrag a road from the camp to your town.
  3. Build the Supply YardSend it 160 logs. It stores the town's building materials.
  4. Build the Market240 more logs, carried by a yard truck.
  5. Sell foodAdd a ranch and an orchard. Milk and fruit sell to the Market, and your town starts to grow.

Five tiers

Each tier opens new buildings and bigger goals. The free demo covers Tiers 0 and 1, and ends when you reach Tier 2.

Maps

Three worlds to play

Each map is shown flat here. In the game it wraps round a globe. The demo plays Map 1. All three maps are in the full game, on the desktop.

Map 1: The Known World In the demo

Built to teach. A small, friendly world where every good is within reach and the island goods need ships. This is the map the free demo plays, and the best place to learn the game.

  • 33 towns
  • island goods by ship
  • demo and full game

Map 2: The Continental Full game

Built for rivers, ports and planes. Four continents and about 46% sea. Coffee, mangoes and oil lie overseas, so you have to build ports and use aircraft to get them.

  • 55 towns
  • rivers, lakes and a gulf
  • desktop only

Map 3: The Meridian Sea Full game, beta

Built for scale and the long game. Five times the land of Map 2, with a desert continent, sea channels for ships and about 190 towns. It is heavy, so it wants a good graphics card and is not part of the browser demo.

  • 5 times the land of Map 2
  • desert and arid towns
  • 22 sea channels
  • desktop only

White squares are towns, gold squares are cities. Small dots are coffee (brown), mangoes (orange) and oil (black).

Questions

Quick answers

What is in the free demo?

Map 1, and Tiers 0 and 1: your first town, food, lumber, bricks, mechanics and the first town levels. It ends when you reach Tier 2. It is a Windows download, because the game is too big for a browser tab.

Which map should I start on?

Map 1. It is built to teach, and it is the one the demo plays. Map 2 is built for ports and planes, and Map 3 for scale and the long game; both are in the full game only.

Can I play in my browser?

No. The game is too heavy for a browser tab, so it is a Windows download. The free demo is coming soon.

Will it come to Steam?

That is the plan. The button will switch on once there is a page.

Will my save carry over?

Mostly, but not always yet. If a map's land is changed, older saves cannot load. You can always export a save to a file from the menu.

Does it run on a phone or tablet?

Not yet. It is a desktop game, played with a mouse and keyboard. This website works on a phone, but the game does not. Mobile may come much later.
